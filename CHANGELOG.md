# Changes

Each version's full notes are in `docs/releases/`, ready to paste into a GitHub release.

## 0.7.0 (21 Nov 2026)
New versions: a quiet check when the app opens, a small note with Update now / See what's new / Not now, and
Settings › Files & safety › New versions (Check now). See [docs/releases/0.7.0.md](docs/releases/0.7.0.md).

## 0.6.2 (21 Nov 2026)
Focus mode hides the toolbar too (pull it back down with the tab). See [docs/releases/0.6.2.md](docs/releases/0.6.2.md).

## 0.6.1 (21 Nov 2026)
Toolbar hide/show moved out of the top bar: a small arrow at the toolbar's end hides it, and a tab under the middle
of the top bar brings it back. See [docs/releases/0.6.1.md](docs/releases/0.6.1.md).

## 0.6.0 (21 Nov 2026)
No more Menu button: Duplicates, History, Focus mode and Settings are on the toolbar. The toolbar can be hidden
("Hide toolbar" at the top, or Settings › Layout). See [docs/releases/0.6.0.md](docs/releases/0.6.0.md).

## 0.5.2 (21 Nov 2026)
Menu button moved to the far left of the toolbar; fixed the empty "Order by" list. See [docs/releases/0.5.2.md](docs/releases/0.5.2.md).

## 0.5.1 (21 Nov 2026)
"Hide kinds of files" moved to Settings › Files & safety. See [docs/releases/0.5.1.md](docs/releases/0.5.1.md).

## 0.5.0 (21 Nov 2026)
Hide kinds of files (Settings › Layout, right-click, and a new setup guide screen, now 9 screens). Hidden files
stay in their folders, just out of sight. See [docs/releases/0.5.0.md](docs/releases/0.5.0.md).

## 0.4.2 (21 Nov 2026)
"Open files with": craft file types first; other kinds tucked under "Change how other kinds of files open".
The setup guide lists only craft types found in her folder. See [docs/releases/0.4.2.md](docs/releases/0.4.2.md).

## 0.4.1 (21 Nov 2026)
Setup guide: choose from every font on the computer in a drop-down (easy-reading fonts first).
See [docs/releases/0.4.1.md](docs/releases/0.4.1.md).

## 0.4.0 (21 Nov 2026)
First-run setup guide: 8 short screens for the main choices, in plain words, with live changes, Skip, and
"Run the setup guide again" in Settings. See [docs/releases/0.4.0.md](docs/releases/0.4.0.md).

## 0.3.4 (21 Nov 2026)
Right-click menus on files (open, copy, copy to, move, rename, sort later, show in File Explorer, install font,
Recycle Bin) and folders. See [docs/releases/0.3.4.md](docs/releases/0.3.4.md).

## 0.3.3 (21 Nov 2026)
New toolbar: Back/Forward, Undo/Redo, Grid/List and Order by. Fixed blurry text in Settings, menus and pop-ups at
Large/Small text size. See [docs/releases/0.3.3.md](docs/releases/0.3.3.md).

## 0.3.2 (20 Nov 2026)
The Menu button and search box now sit together in the middle of the banner. See [docs/releases/0.3.2.md](docs/releases/0.3.2.md).

## 0.3.1 (20 Nov 2026)
The banner is now the top of the window: no separate Windows title bar, with minimise, maximise and close
built into the banner. A maximised window stops at the taskbar. See [docs/releases/0.3.1.md](docs/releases/0.3.1.md).

## 0.3.0 (3 Nov 2026)
The app rebuilt in C#: much faster, lighter, more thumbnails, bigger preview, keyboard shortcuts.
Fixed capitals-only renames and Put back never replacing a file. Letter spacing setting removed.
Settings start fresh. See [docs/releases/0.3.0.md](docs/releases/0.3.0.md).

## 0.2.3
The Electron version (now in `legacy-electron/`).
