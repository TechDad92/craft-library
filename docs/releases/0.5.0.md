Hide the kinds of files you don't want to see, like spreadsheets or programs in the Downloads folder.

## Installing
1. Download **Craft-Library-Setup-0.5.0.exe** below and run it. It updates Craft Library in place, and all settings, notes and colour labels are kept.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

## What's new
- **Hide kinds of files.** Choose any kinds of file you'd rather not see, such as `.xlsx` spreadsheets or `.exe` programs. Hidden files don't show in your folders, in search, in folder counts or in Duplicates. They are never moved or deleted, just out of sight.
  - **Settings › Layout › Hide kinds of files:** a tick-box for each kind of file in your folders, with how many there are. Kinds that aren't craft files are listed first. A small note there says how many files are hidden right now.
  - **Right-click a file › Hide all .xlsx files** (or whichever kind it is) hides that kind straight away.
- **Setup guide:** a new screen, "Files you'd rather not see", so new users can choose from the start. The guide now has 9 screens.

## Good to know
- Nothing is hidden until you choose to hide it.
- To see hidden files again, untick them in Settings › Layout › Hide kinds of files.
