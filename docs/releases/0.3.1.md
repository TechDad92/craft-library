A small update to how the window looks: the top of the app is now one smooth piece, with no separate Windows title bar above it.

## Installing
1. Download **Craft-Library-Setup-0.3.1.exe** below and run it. It updates Craft Library in place, and all settings, notes and colour labels are kept.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

## What's new
- **The banner is now the top of the window.** The separate grey title bar has gone. The minimise, maximise and close buttons are in the top-right corner of the banner, and close turns red when the mouse is over it.
- Everything the title bar did still works from the banner: drag it to move the window, double-click it to maximise or restore, drag it to the edge of the screen to snap the window, and right-click it for the usual window menu.
- On Windows 11 the window keeps its rounded corners and shadow.

## Fixes
- A maximised window now stops at the taskbar instead of going behind it.
- On a narrow window, the search box gets smaller so the Menu button always fits.

## Changed
- Settings now opens below the banner, so it never covers the close button.
