A new toolbar under the banner, with Back, Forward, Undo and Redo, and sharp text at every text size.

## Installing
1. Download **Craft-Library-Setup-0.3.3.exe** below and run it. It updates Craft Library in place, and all settings, notes and colour labels are kept.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

## What's new
- **A toolbar between the banner and the files**, with:
  - **Back and Forward**, which work like File Explorer's: they go back through the places visited (folders, Duplicates, the Recycle Bin, To sort). They replace the Home button. Alt+← and Alt+→, and the side buttons on a mouse, do the same.
  - **Undo**, which has moved here from the Menu.
  - **Redo**, which does again something that was just undone, on the real files and with the same safety rules. Ctrl+Y works too.
  - **Show as Grid or List**, and **Order by** (Name, Newest first, File type, Largest first), so these no longer need a trip to Settings.
- Resting the mouse on Back, Forward, Undo or Redo shows exactly what each will do, for example "Back to Duplicates" or "Undo: Moved Pink Paper.png to Florals".

## Fixes
- With the text size set to **Large** (or Small), the text in Settings, menus, pop-up windows and messages was blurry. It's now sharp at every size.

## Changed
- The Hidden and Exit focus buttons, and today's progress, have moved from the banner to the right-hand end of the toolbar. The banner now holds just the logo, Menu, search and the window buttons.
- Undo is no longer in the Menu; it's on the toolbar instead.
