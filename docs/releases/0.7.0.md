Craft Library can now tell you when a new version is out, and update itself when you say so.

## Installing
1. Download **Craft-Library-Setup-0.7.0.exe** below and run it. It updates Craft Library in place, and all settings, notes and colour labels are kept.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

This is the last time you'll need to download an update by hand. From now on the app can do it for you.

## What's new
- **New versions.** When the app opens, it quietly looks to see if there's a newer version. If there is, a small note appears in the bottom corner with three choices:
  - **Update now** downloads the new version, closes the app, puts the new version in and opens the app again by itself.
  - **See what's new** opens the notes for the new version in your web browser.
  - **Not now** puts the note away. It will ask again next time the app opens.
- Nothing is downloaded or installed unless you press **Update now**, and you can stop a download at any time.
- If there's no internet, or nothing new, the app says nothing.
- **Settings › Files & safety › New versions** shows which version you have, has a **Check now** button, and lets you switch off the check when the app opens.

## Good to know
- Your files, settings, notes and colour labels are never touched by an update.
- The new version is only ever downloaded from Craft Library's own page on GitHub, and it is checked to be exactly the right file before it's used. If anything doesn't match, it isn't used and nothing changes.
