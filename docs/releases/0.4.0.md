A friendly setup guide that walks through the main choices the first time Craft Library is opened.

## Installing
1. Download **Craft-Library-Setup-0.4.0.exe** below and run it.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
3. On a computer where Craft Library hasn't been used before, the setup guide opens straight away.

## What's new
- **Setup guide.** Eight short screens, in plain words:
  1. Welcome
  2. Where your craft files are, and where new downloads arrive
  3. Easy to read: text size and font (each font is shown in its own style)
  4. Colours: light or dark, colour strength, main colour and background
  5. How your files look: pictures or a list, picture size, details and order
  6. Opening your files: which program opens each kind of craft file
  7. Comfort and safety: a few optional helpers
  8. A summary of the choices, each with a "Change" button
- Every choice shows straight away in the app behind the guide.
- Back and Next on every screen, "Step 3 of 8" at the top, and **Skip** on any screen except choosing the craft folder (the app needs that one).
- If the app is closed partway through, the guide carries on from the same screen next time.
- **Run the setup guide again** at the top of Settings, to go through it again any time.

## Good to know
- People already using Craft Library don't see the guide unless they choose to run it from Settings.
- Everything in the guide can also be changed later in Menu › Settings.
