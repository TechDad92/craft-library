The Menu button moves to the toolbar, and the "Order by" list is fixed.

## Installing
1. Download **Craft-Library-Setup-0.5.2.exe** below and run it. It updates Craft Library in place, and all settings, notes and colour labels are kept.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

## Changed
- **The Menu button is now at the far left of the toolbar**, before Back and Forward. The search box has the middle of the banner to itself.

## Fixes
- **The "Order by" list on the toolbar was empty.** It now offers Name, Newest first, File type and Largest first.
