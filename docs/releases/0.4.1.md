More fonts to choose from in the setup guide.

## Installing
1. Download **Craft-Library-Setup-0.4.1.exe** below and run it. It updates Craft Library in place, and all settings, notes and colour labels are kept.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

## Changed
- **Setup guide, "Easy to read" screen:** the font is now chosen from a drop-down list of every font on the computer, instead of only four.
  - The four easy-to-read fonts are still at the top, each with its short note.
  - Every font's name is written in that font, so you can see what it looks like before choosing.
  - Typing a letter jumps down the list.
- Drop-down lists show the chosen item in the same style as in the list.
