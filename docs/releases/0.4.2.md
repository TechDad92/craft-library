Simpler choices for which program opens each kind of file.

## Installing
1. Download **Craft-Library-Setup-0.4.2.exe** below and run it. It updates Craft Library in place, and all settings, notes and colour labels are kept.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

## Changed
- **Setup guide, "Opening your files":** only lists the kinds of craft file actually found in your folder (pictures, PDFs, cut files, Word documents, zips and fonts), so there's nothing to choose for files you don't have.
- **Settings › Files & safety › Open files with:** craft files are listed first. Every other kind of file found in your folders (like spreadsheets or videos) is tucked away under **Change how other kinds of files open**.

## Good to know
- Programs you've already chosen for any kind of file are kept.
