The rebuilt Craft Library: the same app and the same look, now written in C# so it's quick even on slower computers.

## Installing
1. If an older Craft Library (0.2.x) is installed, uninstall it first: **Settings › Apps › Installed apps › Craft Library › Uninstall**.
2. Download **Craft-Library-Setup-0.3.0.exe** below and run it. No administrator password is needed.
3. Open Craft Library and choose the craft folder. (This version starts fresh, so the folder is chosen once more.)

## What's new
- **Much faster.** Folders open quickly and scrolling stays smooth with thousands of files. Thumbnails appear straight away after the first time.
- **Smaller and lighter.** It no longer carries a whole web browser inside it.
- **Thumbnails for more files**, including SVG cut files, Word documents (the paper picture inside), zip bundles, PDFs and Photoshop files.
- **Bigger, sharper preview picture** when a file is selected.
- **Keyboard shortcuts:** arrow keys to move between files, Enter to open, F2 to rename, Delete to send to the Recycle Bin, Ctrl+Z to undo, Ctrl+F to search, Esc to close.

## Fixes
- Renaming a file to change only its capital letters (for example "flower" to "Flower") now works.
- Putting a file back from the Recycle Bin never replaces a file that has the same name. The returned file gets " (2)" instead.
- The parts of the app that talk to Windows (the Recycle Bin, fonts, default programs and "Open with…") are more reliable now.

## Changed
- The **Letter spacing** setting has been removed.
- Settings start fresh. Colours, fonts and other choices need setting again once.

## Good to know
- If something unexpected happens, the details are saved in `problems.log` in `%LOCALAPPDATA%\Craft Library`.
- This is the first test version of the rebuild, so please mention anything that looks or behaves differently.
