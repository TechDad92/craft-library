A small tidy-up in Settings.

## Installing
1. Download **Craft-Library-Setup-0.5.1.exe** below and run it. It updates Craft Library in place, and all settings, notes and colour labels are kept.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

## Changed
- **Hide kinds of files** has moved from Settings › Layout to **Settings › Files & safety**, below "Open files with". The note saying how many files are hidden moved with it.
