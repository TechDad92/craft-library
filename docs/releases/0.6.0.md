Everything is now on the toolbar, and the toolbar can be hidden for a calmer screen.

## Installing
1. Download **Craft-Library-Setup-0.6.0.exe** below and run it. It updates Craft Library in place, and all settings, notes and colour labels are kept.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

## Changed
- **The Menu button is gone.** Everything that was in it now has its own button on the toolbar:
  - On the left: Back, Forward, Undo, Redo, then **Duplicates** (with how many groups there are) and **History**.
  - On the right: Grid or List, Order by, then **Focus mode** and **Settings**.
  - Duplicates, Focus mode and Settings light up while they're in use. Clicking Settings again closes it.
- On a narrow window, the right-hand buttons move onto a second line instead of being cut off.

## What's new
- **Hide the toolbar** with the **Hide toolbar** button at the top of the window, next to minimise. It becomes **Show toolbar** to bring it back. The same choice is in Settings › Layout, and it's remembered next time.
- If the toolbar is hidden while Focus mode is on, an **Exit focus** button appears at the top, so you can always get back.
