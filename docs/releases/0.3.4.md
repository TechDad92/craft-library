Right-click a file to see everything you can do with it.

## Installing
1. Download **Craft-Library-Setup-0.3.4.exe** below and run it. It updates Craft Library in place, and all settings, notes and colour labels are kept.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

## What's new
- **Right-click menu on files.** Right-click any file, as a picture tile or in the list, to:
  - Open it, or open it with another program
  - **Copy** it, then paste it into a folder, an email or another program (Ctrl+C works too)
  - **Copy to…** another of your folders, keeping the original where it is
  - Move it, rename it, or set it aside to sort later
  - Show it in File Explorer, or install it (for font files)
  - Send it to the Recycle Bin
- **Right-click menu on folders**, to open the folder or show it in File Explorer.
- The keyboard's menu key, or Shift+F10, opens the menu for the selected file.

## Good to know
- "Copy to…" never replaces anything: if a file with that name is already there, the copy gets " (2)".
- Undo and Redo work for copies too. Undoing a copy sends just the copy to the Recycle Bin; the original is never touched.
- Anything switched off in Settings › Buttons & features is left out of the menu too.
